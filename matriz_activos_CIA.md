**Fecha:** 8 de octubre de 2026

**Escala CIA:** Alta = impacto grave si se compromete el pilar; Media = impacto significativo pero limitado; Baja = impacto menor. La clasificación valora el impacto para el activo, no la probabilidad de que ocurra la amenaza.

## Observaciones para la entrega

- Las ubicaciones se refieren a rutas y líneas del código fuente del proyecto; pueden variar si el archivo cambia.
- La columna de evidencia indica qué capturas tomar para adjuntar al trabajo; estas capturas no están incluidas en este documento. No fotografiar ni compartir datos reales de clientes, contraseñas, números de tarjeta, CVV o secretos.
- Las amenazas se basan en el código y el volcado SQL revisados. La configuración real del servidor, HTTPS, cookies y controles de infraestructura debe verificarse por separado antes de afirmar que está presente o ausente.
